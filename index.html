☀ Ra

Reiner Knizia's auction game, against 2–4 computer opponents. A web port of a Visual Basic program written in 2006–08, with a neural-network AI, retuned in 2026.

Modern version

Redesigned for phones and desktops, with dark mode, a scoring breakdown, and the improved AI by default.

Classic version

The original 2008 Windows interface, rebuilt control by control. Uses the original AI by default (switch under Options).
Ra was designed by Reiner Knizia (Alea, 1999). This is a fan-made program; tile images come from the 2005 Uberplay edition.
